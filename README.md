# SB365 PINBALL

선부365 랜덤 추첨 핀볼 웹앱입니다.

## Production

https://sb365pinball-chars9498-1742s-projects.vercel.app

## 주요 기능

- 참가자 이름을 쉼표 또는 줄바꿈으로 입력
- `이름*2`, `이름*3` 형태의 가중치
- 1등 / 꼴등 당첨 모드
- 느리게 / 보통 / 빠르게 속도 설정
- 구슬 이름 표시 및 잔상 효과
- 실시간 도착 순위와 기록
- 당첨자 축포 연출
- 효과음 및 전체화면
- 모바일 / 데스크톱 반응형 UI
- 참가자와 설정값 브라우저 자동 저장

현재 production 배포는 Vercel을 사용합니다.
