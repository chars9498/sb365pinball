# SB365 RANDOM ARENA

선부365 랜덤 순위 추첨 웹앱의 **v4.8 실험 버전** 저장소입니다.

> 기존에 사용 중인 v4.7 핀볼 버전은 그대로 유지하며, 이 저장소의 v4.8에서 멀티게임 기능을 확장합니다.

## 공개 실행 주소

https://sb365randomarena-chars9498-1742s-projects.vercel.app

- 위 주소는 v4.8 4종 세트용 **production 주소**입니다.
- 앱 자체에는 로그인/회원가입 기능이 없습니다.
- Vercel의 배포별 임시 URL 대신 위 production 주소를 사용합니다.

## v4.8 게임 모드

1. **PINBALL** — 기존 긴 코스 핀볼. 갈림길, 회전문, 범퍼, 플리퍼, 슬롯, 이동 게이트를 통과해 골인 순위 결정
2. **GLASS BRIDGE** — 좌/우 발판을 랜덤 선택. 잘못 고르면 추락 페널티 후 재합류하며 먼저 통과한 순서대로 순위 결정
3. **BATTLE ROYALE** — 점점 좁아지는 원형 경기장에서 충돌과 랜덤 충격파로 밀려나며 마지막 생존자가 1위
4. **ROCKET RACE** — 터보, 엔진 과열, 운석, 웜홀 위치 교환, 연료 보급 이벤트가 발생하는 우주 레이스

## 공통 기능

- 참가자 이름을 쉼표 또는 줄바꿈으로 입력
- `이름*2`, `이름*3` 형태의 가중치
- 동일 참가자 색상 유지
- 실시간 LIVE RANKING
- 3배 빨리감기
- 효과음 / 전체화면
- 모바일 / 데스크톱 반응형 UI
- 참가자 입력값 브라우저 자동 저장

## 검증
