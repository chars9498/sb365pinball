# SB365 RANDOM ARENA

선부365 랜덤 순위 추첨 웹앱의 **v4.8 실험 버전** 저장소입니다.

> 기존 v4.7 핀볼 운영 버전은 그대로 유지하며, 이 저장소의 v4.8에서만 멀티게임 기능을 확장합니다.

## 공개 실행 주소

https://sb365randomarena-boxing-chars9498-1742s-projects.vercel.app

- v4.8 전용 production 주소입니다.
- 앱 자체에는 로그인/회원가입 기능이 없습니다.

## v4.8 게임 모드

1. **PINBALL** — 기존 긴 코스 핀볼
2. **BOXING BATTLE ROYALE** — 권투글러브를 낀 구슬들이 가까운 상대를 펀치해 링 밖으로 밀어내는 생존전
3. **ROCKET RACE** — 터보, 엔진 과열, 운석, 웜홀, 연료 보급 이벤트가 발생하는 우주 레이스

## BOXING BATTLE ROYALE

- 기존의 보이지 않는 랜덤 충격파 제거
- 모든 참가자에게 시각적인 권투글러브 표시
- 가까운 상대를 조준하면 예고 동작과 타깃 방향이 보인 뒤 펀치
- 적중 시 `POW!` 효과와 함께 실제 물리 밀림 발생
- 일정 시간마다 폭탄이 등장하며, 폭발 전에 위험 범위를 원으로 표시
- 보호막 아이템 획득 시 약 3초간 펀치/폭탄 밀림 대폭 감소
- 경기 링은 서서히 좁아지고 후반에는 SUDDEN DEATH로 펀치 빈도와 링 축소가 강화됨
- 링 밖으로 나가야만 탈락하며, 튕겨나간 원인을 화면에서 확인 가능

## 공통 기능

- 참가자 이름을 쉼표 또는 줄바꿈으로 입력
- `이름*2`, `이름*3` 형태의 가중치
- 동일 참가자 색상 유지
- 실시간 LIVE RANKING
- 3배 빨리감기
- 효과음 / 전체화면
- 모바일 / 데스크톱 반응형 UI
- 참가자 입력값 브라우저 자동 저장

## 최근 수정

- GLASS BRIDGE 모드 및 관련 엔진 제거
- BOXING BATTLE ROYALE 신규 엔진 `arena.js`로 교체
- 신규 모드 START 시 기존 PINBALL도 동시에 시작될 수 있던 이벤트 라우팅 오류 수정
- PINBALL에서 대체 캔버스가 본판을 덮던 CSS 오류 수정 상태 유지

현재 v4.8은 실험/개선 버전이며 v4.7 운영 버전과 분리해서 관리합니다.
