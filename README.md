# SB365 PINBALL

선부365 랜덤 추첨 핀볼 웹앱입니다.

## Production

https://sb365pinball-v48-chars9498-1742s-projects.vercel.app

## 현재 버전

- v4.8
- LIVE RANKING 숫자 배지를 각 참가자 구슬 색상과 동일하게 표시
- 밝은/어두운 배경에 따라 숫자 글자색 자동 조정

## 주요 기능

- 참가자 이름을 쉼표 또는 줄바꿈으로 입력
- `이름*2`, `이름*3` 형태의 가중치
- 긴 핀볼 코스와 다양한 장애물
- 구슬 이름 표시 및 잔상 효과
- 실시간 순위와 도착 기록
- 3배 빨리감기
- 당첨자 축포 연출
- 효과음 및 전체화면
- 모바일 / 데스크톱 반응형 UI
- 참가자와 설정값 브라우저 자동 저장

현재 production 배포는 Vercel을 사용합니다.
